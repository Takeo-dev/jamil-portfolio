# Jamil Ahmed - Personal Portfolio Website

## 🌐 Overview
This is my personal portfolio website built using **HTML, CSS, and JavaScript**. It showcases my skills, projects, and learning journey as an Information Technology student. The portfolio is designed to be simple, responsive, and beginner-friendly while highlighting my development work.

---

## 🚀 Features
- Fully responsive design for all devices
- Clean and modern UI layout
- Sections for About, Skills, Projects, and Contact
- Smooth navigation between sections
- Project showcase with GitHub links
- Lightweight and fast loading

---

## 💻 Technologies Used
- HTML5
- CSS3
- JavaScript
